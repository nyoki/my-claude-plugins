# 監査チェックリスト

`/doctor` コマンドおよび `cc-doctor` エージェントが参照する詳細な監査基準。

各チェック項目には以下のラベルを付与する:
- **[必須]** — 満たさない場合に機能的な問題やセキュリティリスクがある
- **[推奨]** — 公式ドキュメントや開発者の知見に基づくベストプラクティス
- **[要確認]** — コミュニティの慣例に基づく。状況によっては該当しない場合もある

---

# User Scope (~/.claude/)

## 1. CLAUDE.md（グローバル）

### 構造

- [ ] **[必須]** ファイルが存在する
- [ ] **[要確認]** ファイルが肥大化している可能性がないか確認する。グローバル CLAUDE.md は全セッションで読み込まれるため、簡潔に保つことでコンテキストの圧迫を防げる傾向がある
- [ ] **[推奨]** セクションが論理的に整理されている

### 内容の適切さ

- [ ] **[要確認]** 言語設定（対話言語、コメント言語）を明示すると、多言語環境で意図しない言語切り替えを防げる傾向がある
- [ ] **[推奨]** プロジェクト固有の情報が混入していない
  - 特定リポジトリのパスやディレクトリ構造
  - 特定プロジェクトのビルドコマンド
  - 特定プロジェクトのコーディング規約
- [ ] **[要確認]** 抽象的な精神論（「Senior engineer として振る舞え」等）よりも、具体的な行動指示のほうが良い結果になる傾向があると言われている
- [ ] **[推奨]** 古い情報が残っていない（廃止されたモデル名、古い機能への言及等）

### ワークフロー定義

- [ ] **[推奨]** サブエージェントの使い方が定義されている（任意だが推奨）

## 2. settings.json（グローバル）

### 権限設定

- [ ] **[必須]** ファイルが存在する
- [ ] **[必須]** `allow` に過剰な許可がない
  - `Bash(rm:*)` や `Bash(sudo:*)` のような危険なパターンがないこと
  - ワイルドカードの使用が最小限であること
- [ ] **[推奨]** `deny` で危険な操作をブロックしている

## 3. agents/

### 存在確認

- [ ] **[推奨]** ディレクトリが存在する（エージェントを使用している場合）

### 各エージェントの品質

- [ ] **[必須]** `name` が lowercase letters and hyphens で構成されている（公式ドキュメント準拠）
- [ ] **[要確認]** `name` が短すぎたり長すぎたりしないか確認する。用途が推測できる名前にすると管理しやすい傾向がある
- [ ] **[推奨]** `description` に、Claude がいつこのエージェントに委譲すべきかが明確に記述されている（例: "Use this agent when..." で始めるなど）
- [ ] **[推奨]** `description` に `<example>` ブロックを含め、具体的な使用場面を示している
- [ ] **[推奨]** `model` が指定されている（inherit, sonnet, opus, haiku）
- [ ] **[推奨]** `tools` が必要に応じて制限されている（分析系は Read/Grep/Glob のみ等）
- [ ] **[推奨]** 本文に以下が含まれている:
  - 役割・責務の定義
  - 具体的な手順
  - 出力フォーマット
- [ ] **[推奨]** 「対象外」のスコープが定義されている

### 未使用エージェントの検出

- [ ] **[要確認]** ファイル名から用途が推測できないエージェントがないか
- [ ] **[推奨]** 重複する役割のエージェントがないか

## 4. skills/

### 存在確認

- [ ] **[推奨]** ディレクトリが存在する（スキルを使用している場合）

### 各スキルの品質

- [ ] **[推奨]** frontmatter に `name`, `description`, `version` がある（プラグインスキルの場合）
- [ ] **[推奨]** `description` にトリガー条件が明確に記述されている（例: "This skill should be used when..." で始めるなど）
- [ ] **[推奨]** 手順が具体的に記述されている
- [ ] **[推奨]** トリガー条件が明確

## 5. plugins/

### 管理状態

- [ ] **[推奨]** インストールされたプラグインの一覧が把握できる
- [ ] **[必須]** シンボリックリンクが切れていないか
- [ ] **[要確認]** 使用していないプラグインが残っていないか。不要なプラグインはコンテキストを消費する可能性がある

## 6. memory/

### 状態確認

- [ ] **[推奨]** MEMORY.md が存在する
- [ ] **[必須]** MEMORY.md が 200行以内に収まっている（200行以降は Claude Code により切り詰められる）
- [ ] **[要確認]** 古い・不正確な情報が残っていないか
- [ ] **[推奨]** CLAUDE.md と重複する情報がないか
- [ ] **[推奨]** トピック別ファイルが適切に分離されているか

## 7. keybindings.json

### 状態確認

- [ ] **[要確認]** デフォルトのキーバインドと競合するカスタムバインドがないか
- [ ] **[要確認]** 未使用のカスタムバインドが残っていないか

# Cross-Scope Checks（scope: all の場合のみ）

## 重複・矛盾

- [ ] **[推奨]** user と project の CLAUDE.md に重複する記述がないか

# 評価基準

各観点の評価:

| 評価 | 基準 |
|---|---|
| ✅ 良好 | チェック項目をすべて満たしている |
| ⚠️ 改善余地 | 一部のチェック項目を満たしていない（機能に影響なし） |
| ❌ 要対応 | [必須] のチェック項目を満たしていない（品質や安全性に影響） |
| ➖ 該当なし | そのコンポーネントを使用していない |
